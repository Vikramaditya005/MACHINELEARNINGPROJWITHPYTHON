## Project Description

This project develops a Deep Learning-based regression system to predict the fare amount of a New York City taxi trip using trip-related, temporal, and geolocation features. The project includes exploratory data analysis, geolocation and ridership analysis, data preprocessing, feature engineering, feature scaling, deep feedforward neural network development, model evaluation, hyperparameter tuning, and deployment.

## Dataset

The project uses the **Uber Fares Dataset** (Kaggle), which shares the same schema as the NYC Taxi Fare Prediction dataset.

**Target Variable:** `fare_amount`

### Features

- pickup_datetime
- pickup_longitude
- pickup_latitude
- dropoff_longitude
- dropoff_latitude
- passenger_count

The target is a continuous numerical variable, making this a **regression problem**.
